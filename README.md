# Bank Dashboard

A responsive bank dashboard with a sidebar navigation built with React, TypeScript, and Tailwind CSS.

## Features

- **Responsive Sidebar**: Fixed sidebar with 250px width and 1183px height
- **BankDash Branding**: Logo and title in #343C6A color
- **Navigation Items**: Dashboard, Transactions, Accounts, Investments, Credit Cards, Loans, Services, My Privileges, Settings
- **Icons**: Each menu item has a corresponding icon from lucide-react
- **Mobile Support**: Hamburger menu for mobile view with slide-in sidebar
- **Overlay**: Dark overlay when mobile menu is open

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)

## Sidebar Specifications

- Width: 250px
- Height: 1183px
- Opacity: 1
- Brand color: #343C6A
- Fully responsive with mobile hamburger menu
